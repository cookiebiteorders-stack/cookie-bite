## 📋 PART 1 — The Master MD Prompt (copy & paste this)

```markdown
# 🎁 Build a "Build Your Own Gift Box" Feature for Cookie Bite

## 🧠 Context
I run a bakery/sweets brand called **Cookie Bite**. On my website's **Gifts** page,
I want to add a **fully customizable gift box builder** where customers can:
- Pick a box (size / style / occasion)
- Fill it with any products from my catalog (cookies, brownies, chocolates, drinks, etc.)
- Add an optional handwritten / printed message
- Personalize the box (ribbon color, sticker, theme)
- See a live visual preview of their box as they build it
- Checkout the final custom box as a single product

## 🎯 Goal
Create a smooth, fun, "gamified" gift-building experience that increases
average order value and makes gifting feel personal and emotional.

---

## 🧩 Core Functional Requirements

### 1. Box Selection (Step 1)
- User picks a box size:
  - Small (fits 6 items)
  - Medium (fits 12 items)
  - Large (fits 20 items)
  - Premium / Luxury (wooden or magnetic box, fits 15 premium items)
- Each box has:
  - Base price
  - Max item capacity
  - Visual mockup (top-down photo)
- Optional: pick a **theme/occasion** (Birthday, Ramadan, Eid, Wedding, 
  Graduation, Anniversary, Thank You, Get Well, Corporate, Just Because).

### 2. Product Picker (Step 2)
- Show all available Cookie Bite products in a grid:
  - Cookies (by flavor)
  - Brownies
  - Chocolates / truffles
  - Mini cakes / cupcakes
  - Drinks (coffee sachets, hot chocolate, tea)
  - Add-ons (plush toy, candle, flowers, balloon, mug)
- Each product card shows: image, name, price, "+ / –" quantity buttons
- Filter by category, dietary (vegan, gluten-free, nut-free), price
- A **capacity bar** shows: "8 / 12 items used" with progress fill
- Prevent exceeding box capacity (or upsell to bigger box)

### 3. Personalization (Step 3)
- **Optional message card**: textarea (max 250 chars) + sender/recipient name
- Choose **card design**: birthday, romantic, minimalist, kids, Eid, corporate
- **Ribbon color** picker (gold, red, black, pastel pink, etc.)
- **Sticker / wax seal** with initials
- **Gift wrap style**: kraft, luxury black, floral, transparent
- Upload a **photo** (optional, printed on the card)
- Optional **voice/video message** via QR code on the card

### 4. Live 3D / 2D Preview (Step 4)
- A live visual of the box updating as user adds items
- Drag-and-drop arrangement (optional advanced feature)
- Show ribbon + card + sticker live
- "Shake the box" animation for fun 🎉

### 5. Review & Checkout (Step 5)
- Summary of: box, items, personalization, total price
- Delivery options:
  - Same-day / scheduled delivery (pick date + time slot)
  - Gift directly to recipient (hide price, add delivery address)
  - Anonymous sender option
- Add a **"Surprise Delivery"** toggle (no preview notification to recipient)
- Payment + confirmation

---

## 🎨 UX / UI Guidelines
- Mobile-first, swipeable steps
- Sticky bottom bar: "X / Y items • Total: $ZZ • Next →"
- Warm, bakery-feel colors (cream, chocolate brown, gold accents)
- Smooth micro-animations when adding items (item flies into box)
- Confetti animation on completion 🎊
- Save progress (localStorage) so user doesn't lose box on refresh
- "Save as Draft" / "Share my box link" feature

---

## 🛠️ Tech Suggestions
- Frontend: React / Next.js or Shopify Section with Alpine.js
- State management: Zustand or Redux for box contents
- Image preview: layered PNGs or Three.js (for 3D)
- Backend: store custom box as a "bundle" line item in the cart
- Shopify: use Bundle Products API or apps like "Bundler" / "Kaching Bundles"
- WooCommerce: WPC Composite Products plugin
- Custom: Node.js + MongoDB for box configs

---

## 📦 Deliverables
1. Figma design of all 5 steps (desktop + mobile)
2. Frontend component (React/Vue/HTML)
3. Cart integration (single custom-box line item)
4. Admin dashboard to view/fulfill custom box orders
5. Email confirmation with box contents + personalized message preview

---

## 💡 Bonus Features (Phase 2)
- AI suggestion: "Based on the occasion, we recommend these items"
- Subscription: "Send a custom box every month"
- Corporate bulk orders (upload Excel of recipients)
- Loyalty points: earn 2x points on custom boxes
- Refer-a-friend: share your box → friend gets 10% off
- Re-order previous custom box with one click
- "Mystery Box" option: let Cookie Bite surprise the recipient
```

### 📱 UX Micro-interactions
- Item "flies" into box animation when added
- Box "shakes" when you click it 🤣
- Capacity bar fills with chocolate dripping animation
- Confetti when box is complete
- Sound effects (optional, with mute)
- Haptic feedback on mobile

### 💰 Pricing Psychology
- **Anchor pricing**: show "Save $X vs. buying individually"
- **Bundle discount**: 10% off when box is 80%+ full
- **Free shipping** threshold (e.g., free over $50)
- **Free message card** included → feels like a bonus
- **Premium upsell**: "Upgrade to wooden box for +$10"

### 📊 Backend / Admin Ideas
- Dashboard showing most-picked items in custom boxes
- "Build heatmap" – what people choose together (cross-sell data!)
- Auto-generated packing slip with box layout image for your team
- Print label with recipient's message
- SMS to recipient: "🎁 A gift from [Sender] is on the way!"

### 🌟 Marketing Angles
- "Build a box, build a smile" 🍪

- Wedding/event partnerships – bulk corporate boxes
